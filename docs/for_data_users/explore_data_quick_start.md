# Explore Data - Quick Start

Use this quick start guide to launch notebook environments based on whether a data provider has supplied pre-packaged notebooks.

## If pre-packaged notebooks are provided

1. [Click the Explore the Data link](launch_environment.md) on the dataset landing page.
2. [Log in](../getting_started/login_join_project.md) with your MSD-LIVE account.
3. The provided notebooks are already loaded in the environment and ready to run.

## If no pre-packaged notebooks are provided

1. [Click the Explore the Data link](launch_environment.md) on the dataset landing page.
2. [Log in](../getting_started/login_join_project.md) with your MSD-LIVE account.
3. [Create a notebook](create_notebook.md) to get started.
