# Find Data

Please go the the Data Repository's <a href="https://data.msdlive.org/search" target="_blank" rel="noopener noreferrer">**Search**</a> page to find data or code to use for your research. The search page allows you to search across all the datasets and code stored in MSD-LIVE using the same metadata properties captured in the upload form. Note that you will only be able to see datasets for which you have the correct permissions. Over the next year we are working to add the ability to connect data hosted in the Data Repository to cloud computing resources in MSD-LIVE.
