# Set Up Compute Resources

As the core MSD-LIVE infrastructure is built on top of the AWS cloud, we can provide the ability to quickly provision scalable compute resources for your project's needs. This can include things like Jupyter Hub/Jupyter Notebooks for demos, workshops, or research, web application frameworks, and scalable compute clusters for running models or analytics. Because cloud resources are provisioned via reusable templates, this reduces the time to set up such resources to a matter of minutes. Over time, MSD-LIVE will be adding more and more templates tailored to the MSD community. Please see the <a href="https://msdlive.org/computational-resources" target="_blank" rel="noopener noreferrer">**Computational Resources**</a> page for more information including a list of our current offerings.
