# Model Training Notebooks


MSD-LIVE provides interactive Jupyter-based training environments for various MSD models and tools. These environments allow users to learn and practice using models without local installation.

## Available Training Notebooks

### demeter

demeter is an open-source land use and land cover change disaggregation model.

**[Access Training Environment](http://demeter.msdlive.org/)**

---

### GCAM Scenarios

A demonstration on how to conduct scenario adjustments and user modifications in GCAM, including a discussion on scenario design along with several methods for creating and editing scenarios.

**[Access Training Environment](https://gcam.msdlive.org)**

---

### gcamwrapper

Training environment for the GCAM wrapper package.

**[Access Training Environment](https://gcamwrapper.msdlive.org)**

---

### MATILDA

Interactive training for the MATILDA (MultiAgent Transport Infrastructure: Living, Dynamic, And Adaptive) model.

---

### rgcam

Training environment for rgcam, an R package for working with GCAM data.

---

## Getting Started

1. Click on the training environment link for the model you want to learn
2. Authenticate with your MSD-LIVE credentials
3. Follow the guided notebooks to learn the model
4. Experiment with the code and parameters
