# Quick Start

## For Data Users

1. [Find Data](for_data_users/dataset_search.md) - Search the Data Repository for datasets
2. [Create an Account](getting_started/create_account.md) - Required to explore data with notebooks
3. [Explore Data](for_data_users/explore_data_about.md) - Use Jupyter Notebooks to interact with datasets
4. [Download Data](for_data_users/download_datasets.md) - Download datasets to your local machine *(no account required)*

## For Data Providers

1. [Create an Account](getting_started/create_account.md) - Register for an MSD-LIVE account
2. [Join a Project](getting_started/login_join_project.md) - Log in and request project membership
3. [Create a Dataset](for_data_providers/create_dataset.md) - Publish your data to the repository
4. [Upload Your Dataset](for_data_providers/upload_dataset.md) - Upload your files via web or CLI
5. [Enable Exploration](for_data_providers/enable_exploration.md) *(optional but highly encouraged)* - Let users explore your data with Jupyter Notebooks
