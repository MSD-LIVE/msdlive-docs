# Computational Resources


MSD-LIVE harnesses the power of the Amazon Web Services cloud to provide secure, scalable, on-demand computing solutions for MSD projects.

## Available Resources

### Interactive Data Dashboards

Create and deploy interactive web-based dashboards for exploring and visualizing MSD datasets without requiring users to download data.

[Learn more about Interactive Dashboards](interactive_dashboards.md)

---

### Model Training Notebooks

Access cloud-hosted Jupyter environments pre-configured with various MSD models and tools for hands-on learning and experimentation.

[Learn more about Model Training Notebooks](model_training_notebooks.md)

---

### Uncertainty Characterization Resources

Tools and guidance for implementing uncertainty quantification and characterization in MSD research.

[Learn more about Uncertainty Characterization](uncertainty_characterization.md)

---

### Dataset Notebook Environments

Interactive Jupyter notebook environments for exploring datasets with pre-packaged analysis code or creating your own notebooks.

See [For Data Users](../for_data_users/what_you_can_do.md) and [For Data Providers](../for_data_providers/overview.md)
