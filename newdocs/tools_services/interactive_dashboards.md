# Interactive Dashboards


MSD-LIVE users have the ability to create interactive data dashboards which enable downstream users to explore and visualize datasets in MSD-LIVE without having to download the underlying data.

MSD-LIVE harnesses the power of the Amazon Web Services cloud to provide secure, scalable, on-demand computing solutions for MSD projects.

## Available Dashboards

### Lafferty-Sriver 2023 Downscaling Uncertainty

This interactive data dashboard allows users to create different visualizations of the dataset underpinning the Lafferty and Sriver 2023 paper published in NPJ Climate and Atmospheric Science.

**[Access Dashboard](https://lafferty-sriver-2023-downscaling-uncertainty.msdlive.org)**

---

### ICoM RAFT Hurricane Projections Dataset

This dashboard visualizes any of the 620 historic tropical cyclones from 1979 to 2018 replayed under eight different future climate scenarios.

**[Access Dashboard](https://raft-hurricane-projections.msdlive.org/)**

---
