# What You Can Do with Notebooks

MSD-LIVE allows users to **interactively explore data** in the MSD-LIVE data repository using Jupyter Notebooks within MSD-LIVE's Notebook Lab. This feature lets users explore, analyze, and subset datasets directly in the cloud without downloading files locally.

## Key Capabilities

When you explore a dataset using notebooks, you can:

- **Run code directly against the data** — Execute Python, R, or Julia code without downloading anything
- **Use pre-packaged notebooks** — If the dataset author provided example notebooks, you can run them immediately to visualize and understand the data
- **Create your own notebooks** — Write custom analysis, visualization, or subsetting routines
- **Access multiple datasets** — Load and work with other public datasets that have file exploration enabled
- **Download processed results** — Save subsets or processed data and download them via the Jupyter interface or MSD-LIVE's [Command-Line Interface (CLI)](../tools_services/cli_installation.md)

!!! note 
    Jupyter Notebook sessions are limited to **1 hour**.
